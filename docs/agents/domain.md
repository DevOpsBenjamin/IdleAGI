# Domain Modeling: IdleAGI

## Conventions

- Le fichier `CONTEXT.md` à la racine est le **glossaire canonique unique** des concepts du domaine de IdleAGI (Project Singularity Loop).
- `CONTEXT.md` contient uniquement les définitions, règles métier et flux de ressources. Zéro détail d'implémentation framework.
- Les décisions architecturales majeures, irréversibles et structurantes sont consignées dans `docs/adr/NNNN-<slug>.md`.
