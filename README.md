# IdleAGI 🤖⚡

An incremental idle game where you build, scale, and upgrade AI models and datacenter infrastructure to generate tokens and dollars on the path to AGI.

## 🪙 Core Concepts
- **Tokens / sec**: Research, fine-tune, and train advanced AI architectures.
- **Dollars ($)**: Buy GPUs, expand server clusters, optimize cooling, and monetize inference APIs.
- **The Goal**: Reach Artificial General Intelligence (AGI).
